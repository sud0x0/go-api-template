## Files in this directory

- `OWASP_Application_Security_Verification_Standard_5.0.0_en.pdf` — the standard, verbatim
  (title page: *Version 5.0.0, May 2025*), downloaded from the official release
  <https://github.com/OWASP/ASVS/releases/tag/v5.0.0>.
- `asvs-5.0.0.txt` — a plain-text extraction of that PDF (`pdftotext -layout`), committed so
  agents can `grep` the requirements. It is a mechanical reproduction of the same CC BY-SA 4.0
  material and carries the same licence and attribution.
- `asvs-map.md` — a derived work: this repository's applicability map against ASVS 5.0.0.
  It paraphrases requirements rather than reproducing them; as an adaptation of CC BY-SA 4.0
  material it is likewise shared under CC BY-SA 4.0.
