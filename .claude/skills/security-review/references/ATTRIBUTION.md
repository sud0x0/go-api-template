## Files in this directory

- `OWASP_Application_Security_Verification_Standard_5.0.0_en.csv` is the official
  machine-readable CSV (`5.0/docs_en`), downloaded verbatim from the official
  release <https://github.com/OWASP/ASVS/releases/tag/v5.0.0>. It is the committed
  upstream source for this directory. This repo uses the CSV rather than the PDF.
  The content is identical requirement text.
- `asvs-5.0.0.txt` is a plain-text rendering of that CSV, grouped by chapter and
  section so agents can `grep` the requirements. The requirement text is
  reproduced verbatim from the CSV. It is a mechanical reproduction of the same
  CC BY-SA 4.0 material and carries the same licence and attribution.
- `asvs-map.md` is a derived work: this repository's applicability map against
  ASVS 5.0.0. It paraphrases requirements rather than reproducing them. As an
  adaptation of CC BY-SA 4.0 material it is likewise shared under CC BY-SA 4.0.
